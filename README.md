# gestion-universitaire-
L'objectif principal est de remplacer les processus manuels par une solution numérique intégrée afin de :  Gérer efficacement le cycle de vie de l'étudiant (de l'inscription à la remise des diplômes).  Optimiser la planification des ressources (salles, emplois du temps).  Assurer la transparence des évaluations et du suivi académique.
